# Сан-Ремо · концепция сайта

Независимая демонстрационная концепция сайта кафе-кондитерской и пиццерии «Сан-Ремо», Таганрог. Подготовлена для презентации владельцу. Не является официальным сайтом кафе.

## Просмотр

Публичная ссылка: https://kevorik.github.io/sanremo-taganrog-demo/

Статический сайт без сборки и зависимостей. Для локального запуска: `python3 -m http.server 4173`, затем открыть `http://localhost:4173`.

## Что работает

- Адаптивная верстка и мобильная навигация.
- Фильтры категорий и карточки с подробностями.
- Окно связи с телефонным звонком, копированием номера и переходом в VK.
- Аккордеон с поводами посетить кафе.
- Переход к адресу в Яндекс Картах.
- Анимации появления и бегущая строка с поддержкой prefers-reduced-motion.
- Клавиатурная навигация, нативные модальные диалоги, возврат фокуса.
- Локальные фотографии и шрифты, без сторонних запросов при загрузке.

## Перед официальным запуском

Подтвердить у владельца контактные данные и график; добавить настоящее меню, цены, состав и фотографии блюд/зала; согласовать брендинг и тексты. Формы не собирают данные, онлайн-заказы и бронирования не отправляются. Бронь подтверждает сотрудник кафе. Карта декоративная; точный маршрут открывается в Яндекс Картах. Индексация отключена для концепции.

Источники и происхождение изображений — в docs/SOURCES.md. Промпты созданных изображений — в docs/IMAGE-PROMPTS.txt.
